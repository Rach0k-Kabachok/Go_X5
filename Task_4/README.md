# Практика к уроку 5

Диспетчер уведомлений с обработкой ошибок.

## Задачи

- Добавить `ErrEmptyMessage` и обёртку через `%w`.
- Написать `SendError` с методами `Error`, `Unwrap` и `Is`.
- Проверить причину через `errors.Is`, а тип — через `errors.As`.
- Перехватить панику в `SafeSend`.

`Unwrap` возвращает исходную причину. Собственный `Is` сравнивает канал.
Диспетчер останавливается при первой ошибке.

В `main` показаны обычная рассылка, пустое сообщение и паники в `Send`
и вложенном `Log`. Значение `"panic"` используется для вызова паники в логгере.

## Запуск

Из папки `Task_4`:

```sh
go run .
go test ./...
go vet ./...
```
