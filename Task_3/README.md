# Практика к уроку 4

Диспетчер уведомлений с каналами email и push.
Отправка имитируется выводом в консоль.

## Задачи

- Описать интерфейс `Notifier` с методом `Send`.
- Сделать `EmailNotifier` и `PushNotifier`.
- Встроить `BaseNotifier` с полем канала и методом `Log`.
- Передать `[]Notifier` в `Dispatch`.
- Проверить type assertion и вызовы тестами.

Диспетчер останавливается при первой ошибке.

## Запуск

Из папки `Task_3`:

```sh
go run .
go test ./...
go vet ./...
```
